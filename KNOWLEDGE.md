# EngBegginerBot — база знаний

## Устройство

Личный репетитор английского (@eng_begginer_bot) на aiogram 3 + Gemini (google-genai). Отвечает только владельцу (ADMIN_ID).

Что умеет:
- свободный чат с репетитором (исправляет ошибки, объясняет грамматику, переводит), история последних 10 обменов в памяти, /reset очищает;
- «📖 New Text» / /text [тема] / сообщение «new text …» — текст на английском + перевод, кнопка добавляет слова из текста в словарь;
- словарь: /words, /add word - перевод (без перевода — переводит Gemini), /del word, карточки /quiz (чаще показывает слова, которые не знаешь);
- неправильные глаголы: таблица /verbs (123 глагола, страницы), поиск /verb go или /verb идти, тест /verbquiz;
- домашка: /homework — Gemini придумывает задание (с учётом словаря), «Сдать» → ответ одним сообщением → проверка с оценкой;
- ежедневное напоминание в REMINDER_TIME (окно 2 часа после времени, раз в день), спрашивает про несданную домашку; /remind 19:30, /remind off|on;
- уровень A1–C1 в /settings или /level B1.

Модули:
- main.py — запуск, команды бота, цикл напоминаний;
- handlers.py — все обработчики, Session (режим ввода, история чата);
- keyboards.py — клавиатуры;
- ai.py — Gemini: цепочка моделей с паузами при 429/404, structured output;
- verbs.py — таблица неправильных глаголов;
- storage.py — состояние в JSON;
- config.py — переменные окружения;
- logsetup.py — JSON-логи.

Переменные окружения: BOT_TOKEN, ADMIN_ID, GEMINI_API_KEY, TZ (по умолчанию Europe/Kyiv), REMINDER_TIME (по умолчанию 19:00, начальное значение — потом меняется командой /remind и хранится в state.json).

Данные: /app/data/state.json (том eng-data) — уровень, словарь, домашка, настройки напоминания, последний текст. Битый файл переименовывается в state.broken.

## Полезное

- Логи: docker logs eng-begginer-bot (JSON).
- Если Gemini не отвечает — бот пишет «Gemini сейчас недоступен», в логах предупреждения «Gemini model failed» с кодом.
